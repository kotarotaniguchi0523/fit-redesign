# 基本情報技術 I - 使い方ガイド

明治大学「基本情報技術 I」の過去の小テスト（2013〜2017年度）を、登録やログインなしで確認できるサイトです。

**サイト URL**: https://fit-redesign.r02takako.workers.dev

## 基本の使い方

1. トップページで単元と年度を選びます。
2. 問題を読み、自分で答えを考えます。
3. **「答えを確認する」**を押して、解答と解説を確認します。

回答の入力や採点はありません。選択式の選択肢も、選ぶためのボタンではなく問題の一部として表示されます。

### 同じ年度に複数の小テストがある場合

年度ページに対象の小テストがすべて表示されます。ページ上部の小テスト名を押すと、該当する小テストまで移動できます。統合小テストは、複数単元を含むことを明記したうえで全体を表示します。

## Markdownでコピーする

問題カードの **「Markdownでコピー」**を押すと、問題・選択肢・解答・解説をMarkdown形式でコピーできます。ノートやチャットへ貼り付けて利用できます。

## 学習記録

答えを確認した問題と確認日時は、このブラウザに自動保存されます。「記録」ページでは、確認済みの問題、最近確認した問題、前回の続きが見られます。正誤や所要時間は記録しません。

### 別の端末と同期する

Googleログインは使用しません。「記録」ページで秘密の同期リンクを作成し、そのリンクを別の端末で開くと記録を統合できます。

- 同期リンクを知っている人は記録を確認・更新できます。公開しないでください。
- 同期リンクは、信頼できる方法で自分の端末へ送ってください。
- すべての端末から同期を解除し、リンクも失った場合は復旧できません。
- 同期を解除しても、その端末に保存済みの記録は残ります。
- サーバー上の同期データは「記録」ページから削除できます。

## 講義資料

ヘッダーの「講義資料」からPDFを確認できます。問題ページにも、関連資料と元の小テストPDFへの補助リンクがあります。

## よくある質問

### アカウント登録は必要ですか？

必要ありません。端末間同期にもアカウントやGoogleログインは使いません。

### ブラウザのデータを消すと記録は消えますか？

端末内だけに保存している記録は消えます。秘密リンクで同期済みなら、同じリンクからサーバー上の記録へ再接続できます。

### 一部の年度を選べないのはなぜですか？

その単元に該当年度の問題データがないためです。利用できる年度だけがリンクとして表示されます。

### タイマーや正答率はありますか？

ありません。このサイトは、問題を見て答えと解説をすぐ確認することに集中しています。

### スマートフォンでも使えますか？

はい。PC、タブレット、スマートフォンに対応しています。

## 推奨ブラウザ

Google Chrome、Microsoft Edge、Firefox、Safariの最新版を利用してください。
