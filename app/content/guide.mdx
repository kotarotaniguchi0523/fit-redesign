# 使い方ガイド

登録やログインは不要です。したいことを選び、手順に沿って操作してください。

## 問題の答えを確認する

単元と年度を選び、問題の答えと解説を確認します。

1. ヘッダーの<strong>「問題」</strong>を押します。
2. 学習したい<strong>単元</strong>を選びます。
3. 表示された年度から、確認したい<strong>年度</strong>を選びます。
4. 問題を読み、自分で答えを考えます。
5. <strong>「答えを確認する」</strong>を押します。
6. 問題の下に表示された答えと解説を確認します。

答えと解説が表示されれば完了です。同時に、確認した問題がこのブラウザの学習記録へ保存されます。回答の入力や採点はありません。

### 複数の小テストから目的の問題へ移動する

同じ単元・年度に複数の小テストがある場合は、すべて同じページに表示されます。

1. 問題ページ上部の小テスト名を確認します。単元や年度を変える場合は<strong>「単元・年度を変更」</strong>を開きます。
2. 確認したい小テスト名を押します。
3. 移動先の見出しと問題番号を確認します。

年度を選べない場合、その単元には該当年度の問題データがありません。別の年度を選んでください。

## 問題をMarkdownでコピーする

問題・選択肢・図表・答え・解説を、AIやノートで扱いやすいMarkdownとしてコピーします。

1. コピーしたい問題カードを開きます。
2. カード下部の<strong>「Markdownでコピー」</strong>ボタンを押します。
3. <strong>「コピーしました」</strong>と表示されたことを確認します。
4. コピー先のアプリへ貼り付けます。

<strong>「コピーしました」</strong>と表示されればコピーは完了です。<strong>「コピーできませんでした」</strong>と表示された場合は、ブラウザのクリップボード権限を許可してから、もう一度押してください。

## 前回確認した問題から再開する

答えを確認した問題は、このブラウザに自動保存されます。

1. ヘッダーの<strong>「学習記録」</strong>を押します。
2. <strong>「前回の続き」</strong>に表示された問題を確認します。
3. 問題名を押します。
4. 移動先の問題カードを確認し、学習を再開します。

<strong>「最近確認した問題」</strong>からは、直近10件の問題を選べます。記録するのは、答えを確認した問題と確認日時だけです。正誤や所要時間は記録しません。

ブラウザのサイトデータを消すと、端末内だけに保存された記録も消えます。記録を別の端末にも残したい場合は、次の手順で同期リンクを作成してください。

## 別の端末と学習記録を同期する

秘密の同期リンクを使って、2台の端末の記録を統合します。Googleログインやアカウント登録は不要です。

### 最初の端末で同期リンクを作る

1. ヘッダーの<strong>「学習記録」</strong>を押します。
2. <strong>「端末間で同期」</strong>の設定を開きます。
3. <strong>「同期リンクを作る」</strong>を押します。
4. 表示された秘密の同期リンクを確認します。
5. <strong>「リンクをコピー」</strong>を押します。
6. 自分だけが確認できる方法で、リンクをもう一方の端末へ送ります。

### もう一方の端末で記録を統合する

1. コピーした秘密の同期リンクを、もう一方の端末のブラウザで開きます。
2. 記録を統合する確認画面で<strong>承認</strong>します。
3. <strong>「この端末と同期しました」</strong>と表示されたことを確認します。
4. <strong>「答えを確認した問題」</strong>と<strong>「最近確認した問題」</strong>に、両方の端末の記録があることを確認します。

同期後も、各端末の記録はブラウザ内に残ります。必要なときは学習記録ページの<strong>「今すぐ同期」</strong>を押してください。

> 秘密の同期リンクを知っている人は、記録を確認・更新できます。リンクを公開したり、他人へ送ったりしないでください。リンクを失うと同期先の記録を復旧できません。

同期リンクが無効だと表示された場合は、途中で欠けていない元のリンクをもう一度コピーしてください。新しいリンクとの同期に失敗しても、端末内の記録は残ります。

## この端末の同期を解除する

端末内の記録を残したまま、この端末だけを同期先から切り離します。

1. ヘッダーの<strong>「学習記録」</strong>を押します。
2. <strong>「端末間で同期」</strong>の設定を開きます。
3. <strong>「この端末の同期を解除」</strong>を押します。
4. 同期リンクの表示が消えたことを確認します。
5. <strong>「答えを確認した問題」</strong>の件数が変わっていないことを確認します。

解除しても、サーバー上の同期先と他の端末の記録は削除されません。

## サーバー上の同期記録を削除する

現在の同期リンクに保存されたサーバー上の記録を削除します。この操作は元に戻せません。

1. 同期中の端末で、ヘッダーの<strong>「学習記録」</strong>を押します。
2. <strong>「端末間で同期」</strong>の設定を開きます。
3. <strong>「同期先を削除」</strong>を押します。
4. 確認画面の内容を読み、削除を承認します。
5. 同期が解除されたことを確認します。
6. 端末内の学習記録が残っていることを確認します。

削除後は、同じ秘密の同期リンクを別の端末で開いても同期できません。もう一度同期する場合は、新しい同期リンクを作成してください。

## 講義資料を確認する

1. ヘッダーの<strong>「講義資料」</strong>を押します。
2. 確認したい資料を選びます。

問題ページに関連資料へのリンクが表示されている場合は、そのリンクからも開けます。
